## 🤖 Featured Agentic AI Projects

### 📧 **AI-Powered Email Assistant / Ambient Agent**
*   Built an autonomous ambient email agent using **LangGraph** that monitors Gmail, classifies priorities, drafts context-aware replies, and coordinates calendars.
*   Implemented **Human-in-the-Loop (HITL)** approval checkpoints for highly critical actions and built adaptive memory systems that learn from user corrections.
*   *Tech Stack:* `Python`, `LangGraph`, `LangChain`, `OpenAI API`, `Gmail/Google Calendar APIs`, `LangSmith`.
*   Github link: [email-assistant-ambient-agent](https://github.com/chaitanya-jadhav11/email-assistant-ambient-agent)

### 🗂️ **AI-Powered Notes MCP Server**
*   Developed a **Model Context Protocol (MCP)** server enabling external AI agents and LLMs to create, manage, and fetch notes seamlessly through standard interfaces.
*   *Tech Stack:* `Python`, `Anthropic SDK`, `MCP Protocol`, `SQLite`, `UV`.
*    Github link: [AI-Powered Notes MCP Server](https://github.com/chaitanya-jadhav11/notes-mcp)

### 🏷️ **Agentic-sql-rag – Agentic SQL RAG Application**
*   An agentic SQL RAG system that answers natural-language questions about an e-commerce database. Instead of doing a single LLM-to-SQL hop, it runs a multi-step LangGraph workflow that routes, plans, generates, validates, repairs, executes, and analyzes SQL — with automatic retries and conversational memory — exposed over a FastAPI /chat endpoint..
*   *Tech Stack:* `Python`, `LangGraph`, `LangChain`,`Frontier LLMs`, `RAG`, `PostgreSQL`, `LangSmith`, `UV`,  `FastAPI`
*   Github link: [agentic-sql-rag](https://github.com/chaitanya-jadhav11/agentic-sql-rag)
